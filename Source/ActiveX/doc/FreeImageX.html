Installation and basic testing

This Freeimage-ActiveX-library consists of the following COM-objects:

 

Basic COM-objects (no GUI):

FreeImage.Application This object is designed to handle or query global freeimage-detais
FreeImage.Image Open, convert and save images
FreeImage.Multipage Dealing with multipaged images

ActiveX-controls (GUI):

FreeImage.Painting Showing and displaying an image.
